## Quick Start

```bash
# Choose a template directory
cd [template-name]

# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm run dev

# Build for production
npm run build
```

## Features

All templates include:
- ✅ Next.js 15.3.5 with App Router
- ✅ React 19 with TypeScript
- ✅ Tailwind CSS styling
- ✅ @hanzo/ui component library
- ✅ Dark/light theme support
- ✅ Responsive design
- ✅ SEO optimized
- ✅ Production ready

## Customization

Each template can be customized by:
1. Updating branding in `/lib/site.ts`
2. Modifying color schemes in `/app/globals.css`
3. Adjusting components in `/components`
4. Adding new sections as needed

## Deployment

Deploy to any platform that supports Next.js:
- Vercel (recommended)
- Netlify
- AWS Amplify
- Railway
- Render
