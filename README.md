## 🚦 Getting Started

### 1. Choose a Template

Browse templates by:
- **Web Gallery**: Run `cd template-gallery && npm run dev`
- **Catalog**: Read [COMPLETE_TEMPLATE_CATALOG.md](./COMPLETE_TEMPLATE_CATALOG.md)
- **Screenshots**: View files in `screenshots/`

### 2. Check Requirements

Each template needs:
- Node.js (version varies by template)
- Package manager (npm/yarn/pnpm)
- See [TEMPLATE_USAGE_GUIDE.md](./TEMPLATE_USAGE_GUIDE.md) for specifics

### 3. Install and Run

```bash
# Navigate to template
cd template-name

# Install dependencies
npm install

# Start development server
npm run dev  # or npm start, or gulp
```

### 4. Customize

- Read template's README.md
- Check for environment variables (.env.example)
- Modify components and styles
- Test thoroughly before production

## 🎯 Best Practices

### Development

1. **Always read the template's README first**
2. Check for `.env.example` and copy to `.env.local`
3. Use correct Node.js version (check `.nvmrc`)
4. Start with development server before customizing
5. Test responsive design on multiple devices

### Production

- [ ] Remove demo/placeholder data
- [ ] Set production environment variables
- [ ] Run production build locally first
- [ ] Optimize images and assets
- [ ] Test on multiple browsers
- [ ] Set up error tracking
- [ ] Configure analytics

### Component Extraction

When extracting components for reuse:
1. Identify self-contained components
2. Copy component with dependencies
3. Extract required styles
4. Update import paths
5. Document props and usage
6. Test in isolation

See [TEMPLATE_USAGE_GUIDE.md](./TEMPLATE_USAGE_GUIDE.md#component-extraction) for details.

## 🐛 Troubleshooting

### Common Issues

**Port Already in Use**:
```bash
lsof -ti:3000 | xargs kill -9
# or use different port
PORT=3001 npm run dev
```

**Node Version Issues**:
```bash
nvm use 18  # or appropriate version
```

**Module Not Found**:
```bash
rm -rf node_modules package-lock.json
npm install
```

**Build Failures**:
```bash
rm -rf node_modules .next build dist
npm install
npm run build
```

See [TEMPLATE_USAGE_GUIDE.md](./TEMPLATE_USAGE_GUIDE.md#common-issues--solutions) for more solutions.
